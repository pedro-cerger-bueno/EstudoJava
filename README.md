# Estudos em Java

Este repositório reúne os códigos desenvolvidos durante meus estudos práticos em Java.

O objetivo é manter exemplos organizados de diferentes assuntos da linguagem, permitindo consultar e revisar os conteúdos sempre que necessário.

Os estudos incluem desde conceitos básicos, como:

* Variáveis e tipos de dados
* Estruturas condicionais
* Laços de repetição
* Métodos
* Arrays e coleções
* Tratamento de exceções

Até assuntos mais específicos, como:

* Programação Orientada a Objetos
* Encapsulamento
* Herança
* Polimorfismo
* Interfaces

Futuramente, o repositório também poderá incluir estudos relacionados a:

* APIs REST
* Spring Framework
* Spring Boot
* Bancos de dados
* Persistência de dados
* Testes automatizados

Este repositório possui finalidade de estudo, prática e consulta pessoal.
